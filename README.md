# SQL-QUEST-O-ATAQUE-AO-REINO-DOS-DADOS

O reino digital de DataLand vive um momento de crise.
Durante a madrugada, o sistema central da Guilda dos Aventureiros sofreu um ataque causado por um invasor conhecido como NullMaster. O ataque não derrubou o banco de dados por completo, mas alterou diversas informações importantes relacionadas aos jogadores cadastrados.
O problema é que não existe uma cópia recente e confiável da base. Por isso, a equipe responsável pelo banco de dados precisará analisar os registros existentes, entender as regras de negócio da Guilda e corrigir as informações diretamente no sistema.
A direção da Guilda decidiu convocar vocês para realizar essa recuperação.
A partir deste momento, vocês assumem o papel de especialistas responsáveis por restaurar a consistência do banco.
Existe, porém, uma dificuldade importante: as correções precisam ser realizadas na ordem correta.
Algumas alterações realizadas no início do processo influenciam diretamente as próximas etapas. Isso significa que uma decisão incorreta pode causar uma sequência de divergências no banco.
No final da atividade, será realizada uma auditoria geral.
Se todas as alterações forem executadas corretamente, o estado final da tabela deverá coincidir exatamente com o resultado oficial informado ao final deste documento.
Caso exista qualquer diferença, será necessário investigar em qual etapa o erro aconteceu.
Por isso, não tratem as etapas como exercícios independentes.
Todo o processo faz parte de uma única recuperação do banco de dados.
